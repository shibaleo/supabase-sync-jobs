# Free MCP Server 技術仕様書

本ドキュメントは、Free プランとして公開する **MCP（Model Context Protocol）サーバ**の技術仕様を定義する。
要件定義よりも実装・設計寄りの内容とし、**将来の非公開オーケストレーション（同一プロセス内呼び出し）**を前提に据える。

---

## 1. 設計方針（Design Principles）

### 1.1 レイヤ分離の徹底

本システムは以下の関心事を明確に分離する。

* MCP 実装（純粋なドメインロジック）
* 実行エンジン（MCP 呼び出し制御）
* Transport（Streamable HTTP）
* 認証・制限・観測

いかなる MCP 実装も **HTTP / JSON / SSE の存在を知らない** ことを保証する。

---

### 1.2 Orchestrator 内部呼び出し前提

Free MCP は将来、以下の形で利用されることを想定する。

* 外部公開：HTTP 経由
* 内部利用：Go package import による関数呼び出し

このため、MCP は **ネットワーク境界を持たない抽象**として設計される。

---

### 1.3 Streamable HTTP 採用理由

* SaaS / Remote MCP を前提
* 非ローカル環境での利用
* 大規模同時接続
* 将来の Plus / Pro プランとの連続性

stdio Transport は Free MCP のスコープ外とする。

---

## 2. 全体アーキテクチャ

```
[ Client / LLM / Agent ]
          ↓
   Streamable HTTP
          ↓
[ Transport Layer ]
          ↓
[ Execution Engine ]
          ↓
[ MCP Implementation ]
          ↓
[ External Service API ]
```

---

## 3. MCP 抽象仕様

### 3.1 MCP の責務

* 単一サービス・単一責務
* ステートレス
* 同期実行モデル
* 副作用は外部 API 呼び出しのみに限定

---

### 3.2 MCP ライフサイクル

1. 初期化（設定・依存注入）
2. 実行要求の受領
3. 外部 API 呼び出し
4. 結果の構造化
5. 呼び出し元へ返却

MCP 自身は以下を行わない：

* 認証判定
* レート制限
* コンテキスト最適化
* 実行計画

---

## 4. Execution Engine 仕様

### 4.1 役割

Execution Engine は MCP と Transport の中間層として機能する。

* MCP の選択（Free では固定）
* context の生成・管理
* タイムアウト・キャンセル伝播
* 実行時間計測

---

### 4.2 実行モデル

* 同期実行
* 1 HTTP リクエスト = 1 MCP 実行
* goroutine 単位での並行処理

---

## 5. Transport（Streamable HTTP）仕様

### 5.1 通信方式

* HTTP/1.1 または HTTP/2
* Chunked Transfer または SSE
* リクエスト・レスポンスは JSON

---

### 5.2 ストリーミングポリシー

* MCP 実行中の中間状態を逐次送信可能
* 最終結果は必ず送信される
* クライアント切断時は context をキャンセル

---

### 5.3 エラーハンドリング

* プロトコルエラー
* MCP 実行エラー
* 外部 API エラー

すべてを **構造化エラー**として返却する。

---

## 6. 認証・制限仕様（Free プラン）

### 6.1 認証

* API Key ベース
* リクエスト単位で検証

---

### 6.2 レート制限

* リクエスト数制限（QPS）
* 同時実行数制限

制限超過時は即時エラーを返却する。

---

## 7. パフォーマンス仕様

### 7.1 設計目標

* MCP 呼び出しオーバーヘッドを最小化
* JSON 変換は Transport 境界のみに限定
* メモリアロケーションを抑制

---

### 7.2 計測指標

* p50 / p95 レイテンシ
* MCP 実行時間
* 外部 API 待機時間

---

## 8. 観測・ログ

### 8.1 ログ

* リクエスト ID
* MCP ID
* 実行時間
* エラー内容

---

### 8.2 メトリクス

* 実行回数
* エラー率
* レイテンシ分布

Free プランでは簡易実装とし、将来拡張可能とする。

---

## 9. デプロイ・運用

### 9.1 実行形態

* 単一 Go バイナリ
* コンテナ / VM / マネージド環境対応

---

### 9.2 スケーリング

* 水平スケーリング前提
* ステートレス設計

---

## 10. 将来拡張との整合性

### 10.1 Plus プラン

* MCP 動的選択
* 実行計画導入
* コンテキスト削減

---

### 10.2 Pro プラン

* Backend Agent
* 複数 MCP 合成
* 完全内部呼び出し

Free MCP はこれらの **下位互換・基準実装**として位置づけられる。

---

## 11. 非目標（Non-Goals）

* MCP 合成
* 自動最適化
* 学習・進化ロジック
* stdio Transport

これらは Free プランの範囲外とする。
